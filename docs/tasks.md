# Rake Tasks

This file is automatically generated. To regenerate it, run:
```bash
rails docs:generate_tasks
```

| Task | Description |
|------|-------------|
| `articles:backfill_content` | Backfill missing content for articles without content_html or content_md |
| `articles:stats` | Show statistics about articles with missing content |
| `docs:generate_tasks` | Generate task documentation to docs/tasks.md |
| `fixtures:download` | Download website fixtures from separate repository |
| `fixtures:generate` | Generate fixture files from a live URL for mock testing |
| `fixtures:generate_articles` | Generate article fixtures for an existing site (uses existing archive.html) |
| `fixtures:list` | List all available fixture sites |
| `observability:errors:article` | Show errors for an article by id or url [usage: bin/rails 'observability:errors:article[123]'] |
| `observability:errors:job` | Show errors associated to an ActiveJob id [usage: bin/rails 'observability:errors:job[abcd]'] |
| `observability:errors:open` | List latest open errors [usage: bin/rails 'observability:errors:open[20]'] |
| `observability:errors:resolve` | Resolve an error id (status=resolved) [usage: bin/rails 'observability:errors:resolve[1]'] |
| `observability:errors:show` | Show full details for an error id [usage: bin/rails 'observability:errors:show[1]'] |
| `observability:errors:site` | Show errors for a website by id or domain [usage: bin/rails 'observability:errors:site[123]'] |
| `observability:errors:summary` | Print summary of recent errors (default: last 30 days) [usage: bin/rails 'observability:errors:summary[30]'] |
| `sites:list` | List sites |
| `sites:refresh` | Refresh all sites |
| `sites:remove` | Remove a site and all its subscriptions by domain |
| `sites:remove_sub` | Remove a subscription by user and site |
| `sites:show` | Show single site |
| `users:list` | List users |
| `users:show` | Show single user |
